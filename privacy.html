개인정보처리방침 · 서비스 약관 — 리천 앱

“리천 앱”은 리천(마음을 여는 창)이 만든 교사용 앱들이 구글 로그인 화면에서 함께 쓰는 이름입니다 — 시행일 2026년 9월 25일

요약 — 리천 앱은 선생님이 입력한 학생 자료를 선생님의 기기와 선생님이 저장한 파일에만 보관하며, 제작자(리천)의 서버에 저장하지 않습니다. 구글 드라이브 동기화를 켜면 자료가 선생님 본인의 구글 드라이브에만 저장되고, 제작자는 그 내용을 볼 수 없습니다.

1. 이 이름을 쓰는 앱

앱드라이브 폴더앱별 방침
리천 종합의견 AI 빌더리천 종합의견jonghab.richeon.kr/privacy
리천 학급 자리배치 스마트 빌더리천 자리배치seat.richeon.kr/privacy

앱마다 다루는 자료(학생 명단·사진·관찰 기록 등)와 외부 서비스(예: AI 제공사)는 위 앱별 방침에 자세히 적습니다.

2. 구글 드라이브 동기화 (선택)

  • 선생님이 앱에서 [구글 계정 연결]을 누를 때만 쓰입니다. 앱이 요청하는 권한은 drive.file(앱이 만든 파일만 확인·수정·생성·삭제)뿐이며, 드라이브의 다른 파일·Gmail·연락처에는 접근하지 않습니다.
  • 작업 파일은 앱과 구글 사이를 직접 오가며 제작자의 서버를 거치지 않습니다. 웹판의 로그인 토큰 교환만 각 앱 주소의 서버 함수가 대신 하며, 이때 학생 자료는 오가지 않습니다.
  • 구글 계정의 타사 앱 목록에는 “리천 앱” 하나로 표시됩니다. 거기서 액세스 권한을 삭제하면 같은 계정으로 연결한 모든 리천 앱의 드라이브 연결이 함께 끊깁니다. 한 앱만 끊으려면 그 앱의 [연결 해제]를 쓰세요.

3. 구글 사용자 데이터에 관한 약속

리천 앱의 구글 API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. 구글 드라이브에서 얻은 데이터는 선생님이 요청한 동기화 기능에만 쓰고, 광고·판매·다른 목적에 쓰지 않으며, 사람이 읽지 않습니다.

4. 정식판 인증

사용자 ID·인증번호·기기 이름은 리천 인증 센터(auth.richeon.kr)에서 인증 상태 확인에만 사용합니다. 작업 파일과 드라이브에는 들어가지 않습니다.

5. 보관과 삭제

  • 기기의 자료는 각 앱의 초기화 기능으로 지울 수 있고, 저장한 파일은 선생님이 직접 지웁니다.
  • 구글 드라이브의 파일은 드라이브에서 직접 지우거나, 앱의 [연결 해제] 후 앱 폴더를 삭제하면 됩니다.

6. 서비스 약관

  • 정식판은 인증한 개인(교사)이 개인 용도로 사용할 수 있으며 타인과의 공유·재배포는 금지됩니다.
  • 앱은 있는 그대로 제공되며, 자료 유실에 대비해 작업 파일을 따로 보관할 것을 권장합니다.
